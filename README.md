# Story Forge

An interactive LitRPG you play by choosing, narrated like an audiobook. Every chapter ends at a decision; the app tracks your stats, gear, companions and the story's hidden plan, and each character gets their own voice.

- **On your Mac:** double-click `Start Story Studio.command` (or run `npm start`) and open http://127.0.0.1:3210/forge. Needs Node.js 22+ and an OpenAI API key.
- **Online beta:** see `DEPLOY.md` (Render + invite codes).

Built with plain Node.js, no packages to install.
